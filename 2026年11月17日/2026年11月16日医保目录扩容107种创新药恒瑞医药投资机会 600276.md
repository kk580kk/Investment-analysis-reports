# 核心事件

2026年11月16日，2026年国家医保药品目录权威解读发布：本次**新增107种药品**，其中**51种为1类创新药**；商保创新药目录新增12种、总数达28种；目录将于**2027年1月1日**正式执行。同一天，国家发改委将**生物医药**列入"十五五"六大新兴支柱产业。

---

# 未来变化预测（5—10年结构性改变）

1. **创新药从"高价小众"变为"可及的主流治疗手段"**：医保对1类创新药的接纳节奏从"每年零星纳入"变为"批量纳入"，创新药放量周期从上市后5—8年缩短至2—3年。
2. **支付结构固化为三层**：基本医保（保基础）+商保创新药目录（保高值）+按疗效付费/风险分担（保控费），形成可持续的高值药支付体系。
3. **行业出清与集中**：集采压缩仿制药利润，资源向"有真创新、有出海能力"的头部企业集中，中小仿制药企退出或被并购。头部创新药企研发投入强度长期维持20%以上。
4. **出海成为第二增长曲线**：License-out（对外授权）交易金额持续放大，中国创新药从"卖国内"转向"卖全球"，BD收入成为常态化利润来源。
5. **"预进院"机制常态化**：新药进院与医保联动，医院准入速度加快，销售放量前置，销售费用率长期下行。

# 影响分析（MECE六维）

| 维度 | 影响 |
|---|---|
| **经济** | 医保基金支出结构从"仿制药为主"向"创新药+慢病管理"倾斜；创新药产业链（CXO、原料药、制剂）产值提升，成为出口新增长点 |
| **产业** | 创新药企估值体系从"管线数量"转向"商业化能力"；CXO订单结构从海外转向"海外+国内创新"双轮；仿制药企业加速转型或出局 |
| **社会** | 患者自付负担显著下降（高值药自付从数十万降至数万以内）；创新疗法可及性提升，肿瘤、罕见病患者生存期延长；同时医保基金可持续性压力加大 |
| **国际** | 中国创新药在全球BD市场占比持续提升，成为跨国药企的重要管线来源；中美在生物医药领域的合作与摩擦并存（生物安全法案风险） |
| **政策** | 医保目录动态调整机制成熟化；商业健康险与基本医保衔接（丙类目录）制度落地；"十五五"将生物医药列为支柱产业，研发费用加计扣除、审评加速等政策持续 |
| **资产价格** | 创新药板块经历三年调整后进入"业绩兑现期"，估值从PS向PE切换；医保放量确定性提升带来估值修复，但个股分化极大，需精选有商业化能力的龙头 |

# 投资机会判断

**存在机会，且是六条支柱产业中"业绩可验证性"最强的一条。**

逻辑：① 目录执行时间明确（2027年1月1日），放量节奏可测算；② 51个1类创新药纳入，直接对应多家上市公司2027—2028年收入增量；③ 板块估值处于历史中低位；④ 龙头公司现金流稳定、抗风险能力强，适合作为底仓配置。

**标的选择**：优先选择"创新药+仿制药现金流双轮"的大型药企——既有创新药放量弹性，又有成熟产品提供现金流安全垫。

# 投资对象描述

**恒瑞医药（600276，上交所主板）**

- **主要产品/业务**：中国创新药龙头，业务分两块：① **创新药**（占收入主体）——肿瘤药（PD-1抑制剂卡瑞利珠单抗、ADC抗体偶联药物、PARP抑制剂等）、麻醉镇痛药、造影剂、自身免疫病药物；② **仿制药**——提供稳定现金流。通俗讲，它既做"治疗癌症的新型靶向药"，也做"医院常用的麻醉药、造影剂"。
- **研发与出海**：国内研发投入规模最大的药企之一，在ADC、双抗、GLP-1等前沿领域布局丰富，已有多笔对外授权（License-out）交易，形成"国内放量+海外授权"双收入来源。
- **为什么受益**：医保目录批量纳入1类创新药，公司是国产1类新药获批数量最多的企业之一，新增适应症与新产品进院后放量路径清晰；同时仿制药现金流为研发提供持续弹药。

# 风险点

1. **医保降价超预期**：谈判价格大幅低于预期，放量不抵降价，收入弹性削弱。
2. **集采冲击**：仿制药集采续约降价，现金流安全垫受损。
3. **研发失败**：关键III期临床失败或ADC安全性事件，直接冲击估值。
4. **出海不确定性**：License-out交易依赖对方推进，里程碑付款存在不确定性；美国生物安全法案类政策风险。
5. **销售费用与合规**：医院准入与学术推广的合规监管趋严，销售费用率难以下降。
6. **医药板块情绪**：板块整体受政策扰动大，医保控费政策超预期会压制估值。
