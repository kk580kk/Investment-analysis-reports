# 核心事件

2026年11月16日，国家发展改革委在"奋进'十五五'"系列新闻发布会上明确，"十五五"时期重点培育**集成电路、航空航天、生物医药、低空经济、新型储能、智能机器人**六大新兴支柱产业，六大产业去年产值接近6万亿元，"十五五"末有望翻一番、突破10万亿元以上；同一天，证券时报报道国内半导体产业正由"局部国产替代"迈向"全产业链制造体系建设"，国产GPU与半导体设备成为重点方向。

---

# 未来变化预测（5—10年结构性改变）

1. **产业定位从"补短板"变为"支柱产业"**：集成电路由需要财政输血的"卡脖子"环节，转为年产值数万亿的国民经济支柱。政策资源从"点状攻关"转为"全链条体系建设"，设备—材料—制造—封测—EDA形成内部循环。
2. **产业链循环自洽**："需求牵引—国产供给—应用反馈—技术迭代"闭环成形。国内AI算力需求（大模型、智算中心）成为国产晶圆代工的第一需求来源，不再依赖海外客户订单驱动。
3. **成熟制程国产化率过临界点**：国产前道光刻机（上海微电子SSC800/SSB800，关键零部件国产化率超90%、累计支持流片超千万片）已验证可量产运行，成熟制程设备国产化率从"可用"走向"规模化替代"。
4. **产能地理重构**：新增晶圆产能向中西部与粤港澳集中，配套形成区域性产业集群，与"中部崛起"、大湾区政策叠加。
5. **制造环节议价权提升**：国内代工产能长期偏紧（存储与算力芯片同步挤占产能），代工价格与产能配额成为长期稀缺资源。

# 影响分析（MECE六维）

| 维度 | 影响 |
|---|---|
| **经济** | 六大支柱产业产值从近6万亿向10万亿以上抬升，相当于在GDP中新增一个"汽车产业级"板块；集成电路资本开支（设备+厂房）成为固定资产投资的重要增量，替代地产投资的部分缺口 |
| **产业** | 上游设备/材料/EDA从"验证导入"进入"批量供货"；下游国产GPU、存储、车规芯片获得稳定产能保障；海外厂商在中国成熟制程市场份额系统性收缩 |
| **社会** | 高端制造岗位（工艺工程师、设备工程师）需求扩大，半导体人才薪酬结构性上行；消费电子、汽车电子成本端受益于国产供给 |
| **国际** | 中美科技博弈从"单点封锁"转为"体系建设对抗"；中国成熟制程产能占全球比重上升，引发欧美"产能过剩"调查风险；同时为全球南方国家提供非美系供应链选项 |
| **政策** | "十五五"规划以超常规措施全链条推动集成电路攻关，《电子信息制造业发展"十五五"规划》明确做精成熟制程、提高先进制程能力、推动先进封装与宽禁带半导体产业化；大基金三期、超长期特别国债持续投向设备与材料 |
| **资产价格** | 半导体板块从"主题炒作"转为"业绩兑现+估值重塑"；板块内部严重分化——设备/制造端受益于资本开支，存储端受益于涨价，估值体系由PS转向PE；但板块已先行上涨，短期波动放大 |

# 投资机会判断

**存在明确可落地机会，且是六条支柱产业中确定性最高、政策最刚性的一条。**

理由：① 集成电路是六大支柱中唯一被"十五五"规划点名"采取超常规措施、全链条攻关"的领域，政策强度最高；② 需求端有真实订单支撑（存储涨价、算力芯片紧缺），不是纯预期；③ A股有完整标的可交易；④ 板块经历近一个半月回调，估值与位置均较前期改善。

**标的选择逻辑**：优先制造端龙头（受益于产能紧缺+国产替代双重逻辑），其次设备端（受益于资本开支），最后存储端（受益于涨价但周期性强）。

# 投资对象描述

**中芯国际（688981，上交所科创板）**

- **主要产品/业务**：中国大陆规模最大、技术最领先的集成电路晶圆代工厂。通俗讲，就是"替别人造芯片的工厂"——客户（芯片设计公司）把图纸交给它，它用上千道工序在12英寸硅片上刻出电路，按片收费。产品覆盖0.35微米到FinFET工艺，服务智能手机、消费电子、工业与汽车电子、AIoT等领域；同时提供光掩模制造、凸块加工、测试等配套服务。
- **为什么是它**：国内唯一具备规模化先进制程能力的代工厂，是"国产算力芯片"（GPU、AI加速卡）唯一可依托的本土制造平台。只要国产AI芯片放量，它就是绕不开的产能出口。
- **公开经营信息**：据2026年11月16日行业周报，公司预计2026年全年收入超120亿美元，四季度营收指引环比增长4%—6%，产能利用率维持高位。

# 风险点

1. **估值与波动风险**：科创板个股单日波动可达±10%，若板块二次杀估值，可能直接跌穿止损位造成滑点损失。
2. **先进制程设备受限**：若海外进一步收紧设备/零部件出口，扩产节奏可能低于指引。
3. **产能过剩与价格战**：国内多家晶圆厂同步扩产，2028年后成熟制程可能供过于求，代工价格下行。
4. **海外客户流失**：地缘政治导致部分海外设计公司转单，产能利用率存在回落风险。
5. **政策预期落空**：若"十五五"具体资金安排低于市场预期，主题溢价回吐。
6. **汇率因素**：11月15日外汇存款准备金率上调至6%（五年首次上调），人民币升值预期被压制，外资流入节奏可能放缓，影响科创板资金面。
