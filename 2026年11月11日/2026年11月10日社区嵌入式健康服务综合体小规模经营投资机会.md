# 2026年11月10日 四部门打通创新药进院 + 发改委扩容"一老一小"：社区嵌入式健康服务综合体

> **事案日期**：2026年11月10日
> **信息来源**：国家卫健委/医保局/中医药局/疾控局联合通知（2026-11-10 发布）、证券时报（2026-11-10 12:20）、国家发展改革委专题新闻发布会（2026-11-10 10:00）、中国网直播实录（2026-11-10）、《中医药传统知识保护条例》公布（2026-11-10）
> **报告生成日**：2026年11月11日
> **十年影响评级**：★★★★

---

## 一、核心事件

2026年11月10日，医疗健康领域出现三条方向一致的政策：

1. **四部门（卫健委、医保局、中医药局、疾控局）联合印发通知，促进创新药安全合理配备使用**：要求**二级以上医疗机构优化创新药进院流程**，并明确**不得以品规数量、药占比等为由限制创新药配备使用**——创新药"进院最后一公里"被打通；
2. **国家发改委明确引导盘活社区闲置资源，建设"一老一小"社区集成式综合服务设施**，并完善普惠机构认定与价格形成机制、支持水电气热按居民价执行；
3. **《中医药传统知识保护条例》公布**，我国首部中医药传统知识保护行政法规，2027年1月1日起施行——中医药服务与产品的知识产权体系正式建立。

同日相关：湖南公示第十一批国家组织药品集采新增76个品种，集采常态化延续。

**三条政策的共同指向：医疗健康服务的价值重心正从"大三甲卖药"向"社区端服务 + 创新药可及性 + 中医药知识产权"三段迁移。对个人创业者而言，最可直接落地的，是夹在中间的"社区级健康服务节点"。**

---

## 二、未来变化预测（5–10年）

1. **2027–2028年**：创新药进院加速，院外延续性服务（注射、康复、随访、慢病管理）从医院外溢到社区，"医院诊断 + 社区服务"分工成型；中医药服务在社区端的合法边界因《条例》清晰化。
2. **2028–2030年**：社区健康服务综合体（康复 + 慢病管理 + 中医药理疗 + 居家照护 + 辅具租赁）成为标准化业态，连锁化率从不足10%升至30%以上；支付端由"自费为主"转向"医保门诊统筹 + 商业保险 + 长护险"三元结构。
3. **2030年后**：老龄化推动"以社区为单位的健康管理"成为基本公共服务的一部分，单体小店被连锁品牌整合，早期进入者通过被并购实现退出。

## 三、影响分析（MECE六维）

### 1. 经济维度
- 创新药放量带来医保支出结构变化（高价药替代低价药），同时催生"用药管理与随访服务"的新付费场景。
- 社区健康服务属于典型"高频、低客单、本地化"生意，抗电商冲击，能吸纳大量中等技能就业。
- 对宏观：服务消费占居民支出比重提升，是"扩内需"政策的核心抓手。

### 2. 产业维度
- 受益链条：社区康复/理疗机构、居家护理服务商、辅具租赁与适老化改造、中医药连锁诊所、DTP药房与注射服务。
- 竞争格局：极度分散（个体诊所、夫妻店为主），**具备标准化流程+连锁管理能力者胜出**；医院自营的康复科与社区卫生服务中心是最强竞争者。
- 中国特有路径：中医药理疗（针灸、推拿、艾灸）因人力成本低、可标准化、复购高，成为社区健康店最容易跑通的品类。
- 风险信号：医保基金监管趋严，一旦违规刷卡被查，门店直接失去支付通道。

### 3. 社会维度
- 老人"就近获得专业照护"，减少住院与家属陪护压力；慢病管理下沉可显著降低急性发作率。
- 就业结构：康复治疗师、护理员、中医技师需求上升，是"技能型服务业"的代表。
- 信任问题：社区健康服务高度依赖口碑与资质，监管与黑医美/养生骗局的博弈长期存在。

### 4. 国际维度
- 中国"社区+中医"模式在全球老龄化市场中具备独特竞争力，可作为服务贸易与中医药出海（东南亚、中东）的样板。
- 创新药进院加速也使跨国药企在华商业化路径更短，竞争加剧，倒逼本土创新药企加速放量。
- 中医药知识产权立法为中国参与国际传统医学标准制定提供了法理基础。

### 5. 政策维度
- 医疗端：创新药进院不受品规/药占比限制、集采常态化、医保门诊统筹推进、长护险试点扩围。
- 民生端："一老一小"设施纳入社区更新、普惠机构补贴、水电气居民价。
- 中医药端：首部传统知识保护条例（2027年施行），配方与技法获得类知识产权保护。
- 监管端：医保飞检、执业资质、价格公示是三条不可触碰的红线。

### 6. 资产价格维度
- 该路径不直接对应二级市场标的，其"资产"是门店的经营性现金流（EBITDA），估值锚定 5–8 倍年净利或 8–10 倍年EBITDA。
- 相关上市公司（康复器械、中医药、连锁药房）受益于政策，但股价已部分反映，弹性不如门店经营本身。
- 商铺租金：社区一层商业因"一老一小"需求上升，租金回报率有改善空间。

## 四、投资机会判断

**存在，且是三类路径中"政策确定性最高、进入门槛最低、但运营难度最大"的一条。**

判断逻辑：
1. 需求刚性且高频：慢病理疗、康复训练、居家照护是刚需，不受消费降级影响；
2. 政策三向加持：空间（社区闲置资源）+ 成本（水电气居民价、普惠补贴）+ 客源（创新药院外服务外溢）；
3. 单店投入可控（≤300万元），但**成功与否取决于选址、技师留存与医保合规三项能力**，属于"经营型投资"而非"财务型投资"。

---

## 五、投资对象描述

**标的类型：社区嵌入式"健康服务综合体"单店（中医理疗 + 康复训练 + 居家照护 + 辅具租赁 四位一体）。**

具体业务：
1. **中医理疗**（核心现金流）：针灸、推拿、艾灸、拔罐、正骨，主打颈肩腰腿痛与失眠调理，单次 128–268 元，办卡客单价 2000–6000 元；
2. **康复训练**：术后康复、卒中后康复、运动损伤康复，按疗程收费（10次/疗程，2800–5800 元），与周边三甲医院康复科建立转介；
3. **居家照护与上门服务**：助浴、助餐、慢病随访、注射陪护，按小时（60–100元/小时）或包月（3000–6000元/月）收费；
4. **辅具租赁与适老化改造**：轮椅、护理床、助行器租赁（月租80–300元），居家适老化改造（卫生间扶手、防滑、坡道，单户3000–12000元）；
5. **健康零售**：中药饮片代煎、膏方、康复器械、保健品（占比控制在营收20%以内，避免重资产压货）。

一句话直观理解：**它是一家开在小区门口的"中医理疗+康复+上门照护"小店——老人下楼就能做理疗，术后病人不用挤医院做康复，家里人不在时能叫护工上门；政策给它便宜的水电、街道帮它找场地、医院把出院病人转给它，它赚的是复购与年卡的现金流。**

## 六、投资路径：入场/退出价格与核心操作标准

### 路径类型
小规模商业化经营投资（单店投入 ≤300 万元）

### 单店投入与盈利模型

| 项目 | 金额（万元） | 说明 |
|---|---|---|
| 场地改造与装修 | 70 | 300㎡，理疗隔间6间、康复区1间、接待与零售区 |
| 康复与理疗设备 | 45 | 牵引床、中频治疗仪、康复训练器械、艾灸排烟系统 |
| 证照与资质 | 15 | 医疗机构执业许可（中医诊所备案）、消防、卫生 |
| 押金（3个月租金） | 12 | 月租4万元（300㎡，单价约4.4元/㎡/天，社区一层商业） |
| 首批药材与耗材 | 15 | 中药饮片、艾条、辅具首批租赁品 |
| 流动资金（6个月） | 78 | 人工+租金+推广，覆盖爬坡期 |
| **合计** | **235** | **低于300万元上限，预留35万元应急** |

**收入模型（稳定期，第12–18个月）**

| 业务线 | 月收入（万元） | 测算依据 |
|---|---|---|
| 中医理疗 | 12.0 | 日均40人次×200元×30天×50%复购折扣折算 |
| 康复训练 | 6.5 | 25个活跃疗程×3000元/疗程÷1.5个月 |
| 居家照护 | 5.5 | 12个包月客户×4500元 |
| 辅具租赁与改造 | 2.5 | 租赁80件×150元 + 改造4户×6000元 |
| 健康零售 | 2.0 | 中药代煎、膏方、器械 |
| **月营收合计** | **28.5** | 年营收约 342 万元 |

**成本与利润（稳定期月度）**：租金4.0 + 人工14.0（1名店长+4名技师+2名护理员）+ 耗材4.5 + 水电1.2（享受居民价）+ 推广1.5 + 其他1.3 = 26.5 万元；**月净利约2.0万元，净利率7%；加政策补贴（普惠托位/养老床位/适老化改造补贴，年约8–15万元），年净利约 32–47 万元。投资回收期约 5–7 年。**

### 入场/退出价格标准（可直接执行）

> **入场标准：单店总投资 ≤235 万元（上限300万元）；场地月租 ≤4.5 万元（300㎡，单价 ≤5.0元/㎡/天），签约≥8年、含3%年递增与3个月免租装修期；月营收达到 20 万元（盈亏平衡线）后方可追加第二家店。**
>
> **退出标准：单店月净利连续6个月 ≥4 万元（年化净利 ≥48 万元）时，按 6–8 倍年净利（288–384 万元）转让给连锁机构；或累计亏损达 60 万元 / 开业18个月仍未达月营收 18 万元，按设备残值+租约转让（不低于投入的 30%，约 70 万元）止损退出。**

### 核心操作标准（必须全部满足）

| 标准项 | 硬性门槛 | 不满足的处理 |
|---|---|---|
| 选址 | 成熟社区，1.5公里内常住人口≥3万、60岁以上≥20%、无同类中医理疗店 | 换点位 |
| 场地成本 | 月租≤4.5万元，租金占营收比≤15% | 压价或换点 |
| 资质 | 可取得中医诊所备案/医疗机构执业许可 | 放弃（无资质不能做理疗） |
| 医保 | 具备医保定点申请条件（运营6个月后可申请） | 作为中期目标，不作为开业前提 |
| 技师团队 | 开业即到位≥3名持证技师（针灸/推拿），核心技师持股或分成 | 不达标不开业 |
| 客源结构 | 开业3个月内会员≥300人，年卡占比≥30% | 加大社区推广 |
| 合规红线 | 不刷医保、不超范围执业、不虚假宣传 | 零容忍 |
| 盈亏平衡 | 月营收 20 万元以上 | 未达则压缩人工与场地 |

### 建仓/运营/退出与跟踪指标表

| 阶段 | 触发条件 | 操作 | 跟踪指标 |
|---|---|---|---|
| 入场 | 场地、资质、技师三项同时到位 | 签约、改造（3个月） | 街道"一老一小"规划、社区闲置房源 |
| 爬坡 | 开业1–6个月 | 社区义诊、免费体验、年卡预售 | 月到店人次、会员数、复购率 |
| 稳定 | 月营收≥20万元 | 申请医保定点、承接街道普惠服务 | 客单价、技师人效、租金占比 |
| 扩张 | 单店月净利≥4万元连续6个月 | 开第二家店或收购周边小店 | 单店净利率、现金流 |
| 退出 | 达退出标准或触发止损 | 转让/并购/关店 | 连锁机构收购报价、EBITDA倍数 |

## 七、风险点

1. **资质与合规风险（最高）**：中医理疗涉及医疗行为，无证经营或超范围执业将被直接取缔；医保刷卡违规将导致刑事与行政双重责任。
2. **技师依赖风险**：核心技师流失会带走客户，必须用股权/分成绑定，且建立标准化手法与培训体系。
3. **选址误判风险**：社区人口结构判断错误（如实际以年轻租客为主），将导致客源不足，这是单店失败的首因。
4. **竞争与替代风险**：社区卫生服务中心、公立医院康复科提供更便宜甚至免费的服务，价格战难以避免。
5. **现金流风险**：年卡预售虽改善现金流，但若服务交付不足会形成负债，需严格按履约进度确认收入。
6. **政策补贴不确定**：普惠认定、床位补贴、水电气居民价的落地节奏因城市而异，不能将补贴计入基础盈利模型。
7. **扩张陷阱**：单店模型未跑通即开第二家店，是此类小规模经营最常见的失败方式。
8. **纪律要求**：严守投入上限300万元、租金占比15%、退出线18个月，不追加投钱救店。
