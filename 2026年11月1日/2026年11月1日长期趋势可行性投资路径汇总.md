## 八、全局执行纪律

### 8.1 仓位与止损

| 纪律 | 设定 |
|---|---|
| 股票总仓位上限 | 37%（P1 15% + P2 12% + P3 10%） |
| 单标的止损 | 严格按各路径止损价执行，不移动、不摊薄 |
| 组合回撤纪律 | 股票组合回撤 8% → 降仓至 50%；回撤 12% → 清空高估值主题仓（P1 优先减） |
| 现金底线 | 始终保持 ≥30% 现金，应对美联储加息与全球杀估值 |
| 分批原则 | 每条路径两档买入，绝不一次性满仓；首档未成交不追价 |
| 拒绝追高 | 现价高于首档买点 3% 以上时，挂单等待回调，不主动上抬价格 |

| 时间 | 观察事项 |
|---|---|
| 2026年11月2日 | 隔夜逆回购首次操作规模、DR001 与 1.25% 偏离度 |

### 8.3 一票否决项

1. 任一股票标的出现 ST/*ST、立案调查、资金占用、重大治理瑕疵 → 立即剔除，不参与；
2. 上证指数跌破 3400 点且成交量持续萎缩 → 全部股票路径暂停建仓，仅保留现金与实物/经营资产；

4. 房产标的所在城市常住人口连续两年净流出 → 放弃该城市所有房产路径。
